# 🐝 VespaTimer β v2.0 - Notes de Version

**Date de sortie:** Août 2026  
**Type:** Version Bêta (test)

---

## ⚠️ IMPORTANT

Cette version est une **BÊTA**. Ne pas utiliser pour le travail réel de pot-à-mèche.

👉 **Version stable officielle:** [VespaTimer v1.4](https://vespacaution.github.io/VespaTimer/)

---

## 🆕 Nouveautés

### Fonctionnalités Majeures
- **13 frelons** maximum (était 7)
- **Boussole graduée 360°** intégrée et fonctionnelle
- **Bouton Démarrer/Arrêter** combiné (un seul bouton)
- **Historique par frelon** - chaque entrée = un frelon, non doublé
- **Reprendre un pot-à-mèche** depuis l'historique
- **Supprimer des entrées individuelles** d'historique
- **Export/Import d'historique** complet

### Améliorations
- Nettoyage automatique après **90 jours** (était 60)
- Avertissement limite **200 entrées**
- **Ovale 200m×100m** autour des nids estimés
- **13 couleurs distinctes** pour les bordures
- **PDF** se ferme avant impression

### Interface
- **Barre inférieure** (Export/Import + Options)
- **Modale Options** (Langue, À propos, Nouvelles, Installer, APK)
- **Modale Nouvelles** (Notes de version)
- **Boussole** avec graduations complètes 360°
- Cartes **repliables** améliorées
- **Bouton APK** pour téléchargement direct

### Technique
- Icône **PNG** pour toutes plateformes
- Service worker avec **auto-update**(sauf apk)
- **4 langues** avec dictionnaire complet
- Stockage isolé (vd_beta5/vh_beta5/vl_beta5)
- Modification des frelons pendant le chronométrage
