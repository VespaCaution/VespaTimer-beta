ℹ️ À propos de VespaTimer

Bienvenue sur VespaTimer, un site internet qui facilite le travail du pot à mèche, en faisant directement les moyennes et en triangulant le nid selon vos chronométrages.

⚠️ N'oubliez pas de signaler vos observations (frelon, nid, etc.) sur : frelonasiatique.ch

Instructions : remplissez les infos en haut, chronométrez les frelons plusieurs fois (minimum 30 secondes par vol), prenez la direction d'envol avec la boussole, voyez où se trouve potentiellement le nid, exportez dans le format souhaité (PDF pour le télémètre / JSON pour réimporter les données plus tard, GPX/KML pour charger sur des cartes / Export historique pour changer de navigateur ou d'appareil). Pour sauvegarder dans l'historique/refaire l'exercice, appuyez sur Nouveau dans Export/Import.
